# 后端算法脚本目录

该目录用于集中展示项目中与后端分析流程直接相关的算法入口，便于代码归类、项目展示和仓库阅读。

为避免影响现有运行方式与一键流程，当前目录采用“独立入口脚本 + 复用根目录既有实现”的方式组织：

- `data_aggregation.py`：特征加工与基础 ADS 聚合入口
- `demand_forecast_lstm.py`：LSTM 需求预测入口
- `enrollment_matching_cf.py`：协同过滤招生匹配与余弦相似度就业推荐入口
- `rule_mining_fp_growth.py`：关联规则挖掘与培养方案优化入口

说明：

1. 根目录脚本仍然保留，保证 `run_full_pipeline.py` 等现有流程不受影响。
2. 本目录脚本可作为“后端算法模块”统一展示入口，适合课程答辩和代码归档说明。
