# FRONTEND_PAGE_ACCEPTANCE_CHECKLIST

本清单用于人工验收 CAC_DB 前端主要页面。每次重构或演示前建议逐页检查。

## 通用检查项

- [ ] 页面能打开，无白屏。
- [ ] 浏览器控制台无明显报错。
- [ ] Network 中无接口 500。
- [ ] KPI 不全为 0。
- [ ] 图表不是空坐标轴。
- [ ] tooltip 能显示有效业务字段。
- [ ] 筛选条件有效，切换后图表或列表会变化。
- [ ] 标题与当前筛选条件一致。
- [ ] 无明显不合理文案或旧“薪资预测”主链路文案。
- [ ] 页面不引用 mock、fakeData、demoData。
- [ ] “暂无数据”状态与数据库实际情况一致。
- [ ] 图表横轴、图例、长文本不拥挤。
- [ ] 数值口径不误导，例如全部专业不显示平均单专业样本量为总量。
- [ ] 教师端、政府端、公众端数据口径不混用。
- [ ] 无前端硬编码假数据掩盖接口问题。

## 总览页

- [ ] 当前学校默认符合教师端口径。
- [ ] 就业样本、覆盖专业、先导产业指标不全为 0。
- [ ] 岗位需求趋势图展示少量重点方向，图例不拥挤。
- [ ] KPI 与趋势图时间范围一致。

## 需求预测页

- [ ] 页面标题和 Y 轴使用“岗位需求人数预测”。
- [ ] 默认展示未来 12 个月，不展示历史月份补 0。
- [ ] 曲线有区分度和季节波动。
- [ ] 教师端为单校口径，政府端为十校汇总口径。

## 招生匹配页

- [ ] 筛选栏只保留专业选择。
- [ ] 默认可选择“全部专业”。
- [ ] 高匹配生源画像固定展示 Top 10。
- [ ] 切换专业后画像内容变化。
- [ ] 全部专业时第三个 KPI 为“覆盖样本量”。
- [ ] 具体专业时第三个 KPI 为“专业样本量”。
- [ ] 生源画像 y 轴展示省份、选科、分数段、志愿等画像标签。

## 就业推荐页

- [ ] 推荐汇总 KPI 不全为 0。
- [ ] 示例学生 ID 来自接口返回，不是写死为 1。
- [ ] 输入可查学生 ID 能返回 Top-K 推荐。
- [ ] 输入不存在学生 ID 时明确提示“未找到该学生”。
- [ ] 推荐列表显示单位、岗位、行业、相似度、置信等级和理由。

## 培养优化页

- [ ] 专业结构建议总数等于五类主建议数量之和。
- [ ] 培养优化优先级分布有气泡点。
- [ ] 气泡 tooltip 显示专业、薪资、优先级、建议类型和原因。
- [ ] 建议卡片能解释就业、需求、技能缺口或政策热度。

## 关联规则页

- [ ] 高价值规则不全是同一 evidence_score。
- [ ] 规则覆盖非计算机方向。
- [ ] 长规则文本不挤压横轴。
- [ ] tooltip 显示完整 antecedents -> consequents。

## 算法链路页

- [ ] 链路顺序清楚：岗位需求预测 -> 招生匹配 -> 培养优化 -> 就业推荐。
- [ ] 每个算法节点有输入、输出和更新时间。
- [ ] 失败节点有明确提示。

## 分析专报页

- [ ] 专报数字来自数据库接口结果。
- [ ] 高需求专业、高需求岗位、招生匹配、培养建议均有可追溯数据。
- [ ] 不出现硬编码固定数字。

## 政府端总览页

- [ ] 展示十校汇总，而不是单校数据。
- [ ] 各高校就业率、薪资、样本数不完全相同。
- [ ] 行业流向不全部集中在互联网。
- [ ] 地图或院校列表无空学校、空指标。

## 公众端监测页

- [ ] 不展示敏感个人数据。
- [ ] 公开监测指标不全为 0。
- [ ] 风险预警和趋势图口径清晰。
- [ ] 无教师端或政府端内部权限数据泄露。
